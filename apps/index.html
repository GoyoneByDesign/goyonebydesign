Blue download buttons link to real installation files in our GitHub release archive. Grey buttons mean that platform does not have an installer yet.

Preview builds are for testing. Android APKs install directly on Android devices; Windows EXE files run on Windows. An iOS app needs an App Store or TestFlight release—an APK cannot install on an iPhone.
