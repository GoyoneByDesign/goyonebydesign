Install MAX-ALPHA as a web app

This is the available free installation route. It adds MAX-ALPHA to your Home Screen or desktop; it does not install the Mac’s local AI models onto your phone.

iPhone & iPad

  1. Open MAX-ALPHA in Safari.
  2. Open the Share menu (it may be inside More), then choose Add to Home Screen.
  3. If shown, keep Open as Web App on. Tap Add.
  4. Open the MAX-ALPHA icon from your Home Screen.

No downloaded configuration profile is needed. See Apple’s Home Screen instructions.

Android

Open MAX-ALPHA in Chrome. In the browser menu, choose Add to Home screen or Install app when offered. This is a web app, not an APK.

Windows

Open MAX-ALPHA in Chrome or Edge. Use the browser’s install-app option when available. This is a web app, not an EXE installer. See Chrome’s web app instructions.

AI features depend on the model, browser capability and services configured for that device. Installing the interface does not provide unlimited hosted AI or synchronize your device data.

Refresh a Home Screen icon safely

Open the actual app address in Safari, reload it, then use Share → Add to Home Screen. Check the logo in the preview and add a new shortcut alongside the existing one first.

Keep the existing installed web app until you have exported or backed up its local records and verified the new shortcut has the data you need. Installed web apps can have separate local storage. Do not delete the old web app, clear Safari website data, reset the app, or uninstall it just to refresh its icon. An icon update does not move records between installations. Sign in normally for private apps; access controls still apply.

Existing shortcuts may retain an old icon because iOS caches it. If the new preview still shows the old icon, close that Safari tab, reopen the same app URL and reload; keep the original app and its data.
