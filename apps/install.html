Install MAX-ALPHA as a web app

This is the available free installation route. It adds MAX-ALPHA to your Home Screen or desktop; it does not install the Mac’s local AI models onto your phone.

iPhone & iPad

  1. Open MAX-ALPHA in Safari.
  2. Open the Share menu (it may be inside More), then choose Add to Home Screen.
  3. If shown, keep Open as Web App on. Tap Add.
  4. Open the MAX-ALPHA icon from your Home Screen.

No downloaded configuration profile is needed. See Apple’s Home Screen instructions.

Android

Open MAX-ALPHA in Chrome. In the browser menu, choose Add to Home screen or Install app when offered. This is a web app, not an APK.

Windows

Open MAX-ALPHA in Chrome or Edge. Use the browser’s install-app option when available. This is a web app, not an EXE installer. See Chrome’s web app instructions.

AI features depend on the model, browser capability and services configured for that device. Installing the interface does not provide unlimited hosted AI or synchronize your device data.

VIEW4REAL Windows test builds

The current VIEW4REAL package must be published and its download bytes verified before a Windows download is enabled. Previous installers are not offered as the renamed app. There is no Android or iOS installer.

Why some buttons are disabled

Source code, design previews and simulator builds are not phone installers. A platform button becomes available after a distributable build and its download link are verified.

JustMyPick v0.38/build 38 is a signed Android debug test APK verified locally for branding, startup and list preservation. The corrected package is not yet published here. Online features need a configured test backend. Physical-phone validation and an iOS installer remain pending. StatusPing has a separate public v0.1.0 Android test APK; it does not include newer source work.

Updates that keep your work

For MAX-ALPHA, reopen the web app while online or press Check updates. An update may wait until the current task or unsaved work is finished. Check the displayed version afterward.

Native apps have separate release processes. This website cannot automatically replace an installed native app. When a compatible new installer is published, use the new release without uninstalling first unless the release notes explicitly require it.

Release maintenance retains the current version and one previous verified version for recovery. Only obsolete, recorded release artifacts qualify for cleanup. Source history, user data, credentials and personal downloads are preserved. The catalog never deletes files on your phone or computer.
