# MAX-ALPHA local assistant guide

Local inference runs on compatible hardware with downloaded model weights. It has no per-message API charge, but requires storage, electricity and sufficient memory. Model licenses and platform compatibility still apply. Local-model quality varies; check answers and code.

## Conversation

Choose Local AI in Connection settings and use This device to inspect support. A Home Screen installation supplies the app interface; it does not automatically download an AI model or connect to another computer. Hosted AI connections are separate and may have quotas or charges.

## Coding workspace

The Mac companion supports staged source proposals using a configured local coding model. Import a focused project subset, describe the change and edge cases, then inspect before/after files. Export the working copy before closing and run the project's tests. The tool does not execute arbitrary generated code. Large projects may need smaller tasks.

## Documents, bills and accounts

Work studio provides document and spreadsheet exports. Bills & budget uses manually entered amounts and exact arithmetic without a model. Email assistance requires a separately connected account and local AI runtime. Account actions remain reviewed. Phone-call links open a device handler; they do not provide autonomous AI conversations.

## Media and external services

Installing MAX-ALPHA does not include a trained image, full-song or video generator, nor a dedicated store-management service. Such integrations require compatible runtimes, appropriate licenses and tested account connections. A plugin installed in a different AI app is not automatically available inside MAX-ALPHA.
